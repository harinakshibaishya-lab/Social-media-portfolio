# Harinakshi Baishya — Social Media & Content Strategist Portfolio

A polished, recruiter-facing personal portfolio website designed for **Social Media, Social Media Executive, and Content & Social Media roles**.

## Core Focus
- **Pure Social Media & Content Strategy**: Free of software testing, coding, or unrelated technical distractions.
- **Speculative & Demo Projects**: Every project and metric is clearly labeled (`Speculative Brand Project`, `Demo Campaign`, `Independent Analysis`, `Demo Data`).
- **Recruiter-First UI**: Clean editorial aesthetics, interactive showcase filters, 30-day content calendar, and analytics dashboards.

## Key Features
- **Featured Case Studies**:
  - *Brand Refresh (Vela)*: 5 Content Pillars, interactive carousel inspector, and strategy rationale.
  - *Social Launch Campaign (30 Days of Better Mornings)*: 3 thematic phases, 11 asset concepts, CTA and community plans.
  - *Social Media Audit (Glossier)*: Independent analysis, format distribution, and 5 pitch concepts.
- **Content Playground**: 12 interactive content cards with detailed modal inspection (hook, caption, hashtags, CTA, audience).
- **Interactive 30-Day Content Calendar**: Filterable by Platform, Content Type, and Objective, with search.
- **Social Media Analytics**: Format utility comparison and 0–30s retention curve charts.
- **Trend Research**: Trend → Idea → Execution framework.
- **Audit Framework**: 20-point diagnostic checklist with real-time score calculation.

## Tech Stack
- HTML5, CSS3 (Modern Editorial Design System)
- Vanilla JavaScript (Zero bloated frameworks)
- Lucide Icons & Responsive SVG Charts

## Local Development
Open `index.html` directly in any browser, or run:
```bash
node server.js
```
Preview at `http://localhost:3000`.
